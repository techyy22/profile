# Personal Profile

**Welcome!** This repository contains the source code for my personal website, which serves as
a central hub for my projects, technical interests, and professional experience.

The goal of this website is to provide a single place where visitors can learn more about me,
explore the projects I've built, and follow my growth as a software engineer. In addition to
showcasing completed work, I'll use this site to document what I'm learning, the challenges I
overcome, and the skills I'm developing along the way.

Whether you're a recruiter, fellow developer, or simply interested in my work, I hope this
website offers a clear overview of my experience and the projects that have shaped my journey.
